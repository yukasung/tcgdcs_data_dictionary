# Frontend attribution

Documentation shell and presentation are adapted from https://github.com/yukasung/mattersolv_docs at commit 67b31f77a107862ee14f02c916965c117ba35b46 (MIT; see licenses/mattersolv_docs-LICENSE.txt).

The shared frontend uses Nextra 4.6.1: text navbar, standard documentation typography, sidebar, table of contents, blue-accent filter panels, tabular references, and light/dark themes. TCGDCS content, database snapshot and object links belong to this project. MatterSolv application-specific services and database requirements are not part of this frontend adaptation.
