SQL definitions ทั้ง 651 รายการมีข้อมูลในไฟล์ส่งออก ไม่พบ Trigger หรือ Synonym ในผลส่งออกนี้ ขอบเขตนี้ไม่รวม server-level objects และสิ่งที่บัญชีผู้ส่งออกมองไม่เห็น

## ข้อสังเกตที่ยืนยันได้

1. **49 ตารางไม่มี Primary Key ในข้อมูลที่ส่งออก** ไม่ได้หมายความว่ามีข้อมูลซ้ำแล้ว แต่ต้องตรวจเมื่อใช้เป็นแหล่ง JOIN หรืออัปเดต
2. **Foreign Key หนึ่งรายการเป็น Not trusted** คือ `FK_SystemOrgStructure_SystemOrgGroup` ยังเปิดใช้งาน แต่ข้อมูลเดิมไม่ได้รับการยืนยันครบด้วย constraint นี้
3. **มี cross-database references 6 รายการ** ไปยัง `TCG_DCS_DB` อยู่ในกลุ่ม adjustment, TDR และรายงานคดี เปิดดูได้จาก dependency ของแต่ละ module
4. **มีตารางชื่อซ้ำข้าม schema** จึงควรระบุ `dbo`, `eod` หรือ `ncb_internal` ให้ตรงงาน
5. **มีวัตถุชื่อ Backup, copy และ version ตามวันที่** ชื่อเหล่านี้ไม่เพียงพอจะยืนยันว่าเลิกใช้แล้ว

## ส่วนที่ยังไม่ครอบคลุม

- แถวข้อมูลจริง จำนวนแถว การกระจายค่า และสถานะ master
- ความถูกต้องของสูตรทางการเงินและการกระทบยอดผลธุรกรรม
- SQL Agent jobs ตารางเวลา และเส้นทางเรียกจาก application
- Dynamic SQL และการ JOIN ที่เขียนอยู่ในแอปพลิเคชัน
- โครงสร้างและข้อมูลของฐานข้อมูลอื่นที่ถูกอ้างถึง

หมวดงานในพจนานุกรมตารางจัดจากรูปแบบชื่อเพื่อช่วยค้นหา คำอธิบายคอลัมน์แสดงจาก metadata โดยตรง ส่วนข้อความอธิบาย workflow อ้างอิงโค้ดที่ได้อ่าน

## การอัปเดตเอกสาร

แทนที่ไฟล์ `data/schema.json` ด้วย snapshot ใหม่ แล้วรัน `pnpm prepare:data`, `pnpm check` และ `pnpm build` รายการตาราง คอลัมน์ ความสัมพันธ์และโค้ดจะสร้างใหม่จากไฟล์นั้น

บทอธิบายภาษาไทยและจำนวนในหน้าคู่มือเป็นเนื้อหาที่เรียบเรียงสำหรับ snapshot วันที่ 20 ตุลาคม 2026 เมื่อเปลี่ยน snapshot ต้องตรวจข้อความเหล่านี้ตามด้วย
