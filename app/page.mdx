# TCGDCS Data Dictionary

เอกสารโครงสร้างฐานข้อมูล **DB_TCGDCS** สำหรับทำความเข้าใจข้อมูลลูกหนี้ การ์ดหนี้
การรับชำระ บัญชี ปรับโครงสร้างหนี้ คดี และรายงาน NCB พร้อมเปิดดูคอลัมน์
ความสัมพันธ์และโค้ด SQL ที่เกี่ยวข้องได้จากแต่ละหน้า

ความหมายที่ยังต้องยืนยันจากข้อมูลจริงระบุไว้ในหน้า [ข้อสังเกตและขอบเขต](/notes/)

## Reading Guide

1. เริ่มที่ [โครงสร้างและความสัมพันธ์](/architecture/) เพื่อแยกลูกหนี้ LG ความสัมพันธ์ การ์ดหนี้ และรายการเคลื่อนไหว
2. อ่าน [กระบวนการทำงาน](/workflows/) เพื่อดูว่างานรับชำระ TDR คดี และรายงานใช้ข้อมูลส่วนไหน
3. ค้นหาใน [พจนานุกรมตาราง](/tables/) แล้วเปิดดูคอลัมน์ คีย์ ดัชนี และตารางที่เชื่อมกัน
4. เปิด [SQL Modules](/modules/) เพื่ออ่าน Stored Procedures, Functions และ Views ต้นฉบับ
